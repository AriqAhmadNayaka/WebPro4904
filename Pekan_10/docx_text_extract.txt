4. Langkah-Langkah Praktikum
Langkah praktikum disusun berdasarkan perintah pada modul, yaitu membuat folder webstore, mengisi file program, lalu menjalankan hasilnya melalui browser.
Membuat folder proyek bernama webstore.
Membuat struktur file yang terdiri dari index.html, style.css, app.js, folder api, dan folder components.
Mengisi index.html sebagai halaman utama webstore dan menghubungkan style.css, jQuery CDN, serta app.js dengan type module.
Mengisi style.css untuk mengatur tampilan produk, tombol, layout, cart, newsletter, dan responsive design.
Mengisi productApi.js untuk menyediakan data produk secara asynchronous menggunakan Promise.
Mengisi ProductList.js untuk menampilkan daftar produk ke halaman web.
Mengisi Cart.js untuk menampilkan keranjang belanja, total harga, tombol remove, dan checkout.
Mengisi Newsletter.js untuk menampilkan form subscribe dan menangani submit form.
Mengisi app.js sebagai pengatur utama state, render, add to cart, remove cart, filter, sort, dan checkout.
Menjalankan proyek menggunakan Live Server, kemudian membuka halaman webstore di browser.

5. Hasil dan Dokumentasi Program
Hasil dari praktikum ini adalah aplikasi Vanilla JS Web Store yang dapat menampilkan daftar produk dan merespons interaksi pengguna secara dinamis.
Bagian/Fitur
Hasil yang Ditampilkan
Halaman utama
Muncul halaman Electronics dengan breadcrumb, tombol Filters, tombol Sort, daftar produk, dan panel Cart.
Product List
Produk tampil dalam bentuk card berisi gambar, kategori, judul, deskripsi, rating, harga, diskon, dan tombol Add.
Add to Cart
Saat tombol Add diklik, produk masuk ke keranjang. Jika produk sama 
ditambahkan lagi, jumlah/qty bertambah.
Remove Cart
Saat tombol Remove diklik, jumlah produk berkurang. Jika qty habis, produk hilang dari keranjang.
Total Harga
Cart menghitung total dengan reduce() berdasarkan harga dikali qty.
Checkout
Jika cart kosong muncul alert keranjang masih kosong. Jika cart berisi produk, muncul alert checkout berhasil dan cart dikosongkan.
Sort
Produk dapat diurutkan berdasarkan harga naik atau turun.
Filters
Produk dapat difilter untuk menampilkan rating minimal 4.6.
Newsletter
Form email dapat disubmit dan berubah menjadi pesan Thanks for subscribing!.
6. Analisis dan Pembahasan
Program sudah menerapkan konsep Modern JavaScript ES6+ sesuai materi praktikum. Kode dibuat modular dengan import/export sehingga setiap file memiliki tanggung jawab masing-masing.
Konsep Materi
Penerapan pada Program
Module
app.js mengimpor fetchProducts, ProductList, Cart, dan Newsletter dari file berbeda.
State
Variabel state menyimpan kondisi products, cart, sortedAsc, dan filtered.
Immutability
Perubahan cart dan products dilakukan dengan spread operator, map(), dan filter(), bukan mengubah data lama secara langsung.
Arrow Function
Digunakan pada setState, addToCart, removeFromCart, toggleSort, toggleFilter, dan callback event.
Template Literal
Digunakan untuk membuat elemen HTML dinamis pada ProductList, Cart, dan Newsletter.
Functional Programming
Menggunakan find(), map(), filter(), sort(), dan reduce() untuk mengolah data produk dan cart.
Asynchronous JavaScript
fetchProducts menggunakan async function dan Promise untuk simulasi pengambilan data produk.
Event Handling
Tombol Add, Remove, Checkout, Sort, Filter, dan form Newsletter diberi event handler.
jQuery
Newsletter menggunakan jQuery jika tersedia, dan tetap memiliki fallback JavaScript murni jika jQuery tidak tersedia.
Dibandingkan contoh modul, struktur file pada program ini dibuat lebih sederhana karena state dikelola langsung di app.js, bukan dipisahkan ke folder core. Walaupun begitu, konsep yang diminta tetap terpenuhi karena program tetap menggunakan state, module, immutability, component-oriented JavaScript, event handling, dan asynchronous data.
